# 학교 산업안전보건 통합 업무지원 시스템

스마트일정관리의 메인 화면을 기준으로 다음 5개 프로그램을 하나의 로컬 웹 프로그램으로 통합한 저장소입니다.

1. 스마트 일정·업무관리
2. AI 업무지원 챗봇
3. 산업안전보건 대표서식 자동화 19종
4. 시설안전 점검이력
5. MSDS·유해물질 관리

기존 `Form-Automation` 프로그램은 기능과 소스를 보존하여 `modules/forms`에 포함했습니다.

## 바로 실행하기

Windows와 Node.js 20.9 이상이 필요합니다.

1. 저장소를 ZIP으로 내려받아 압축을 풉니다.
2. 루트의 `실행하기.bat`를 더블클릭합니다.
3. 검은 실행 창을 유지한 채 브라우저에서 사용합니다.
4. 종료할 때 `종료하기.bat`를 실행합니다.

통합 메인 주소: `http://127.0.0.1:8080/shell/app.html`

상세 사용법은 [README_실행방법.md](./README_실행방법.md), 변경 및 검증 범위는 [reports](./reports) 폴더를 참고하세요.

## 주요 구조

```text
shell/                  스마트일정 기반 통합 화면
modules/forms/          대표서식 자동화
modules/facility/       시설안전 점검이력
modules/chatbot/        AI 업무지원 챗봇
modules/msds/           MSDS·유해물질 관리
launcher/               시작·종료·상태 점검
reports/                분석·통합·테스트 보고서
```

## 데이터와 보안

- 서버는 `127.0.0.1`에만 열립니다.
- API 키와 실제 업무 데이터는 저장소에 포함하지 않았습니다.
- 실행 로그와 PID는 `runtime`에 생성되며 Git에서 제외됩니다.
- 서로 다른 프로그램의 로컬 데이터를 자동 병합하거나 삭제하지 않습니다.
- OpenAI·Gemini·Supabase 등 선택형 외부 기능은 사용자가 별도로 설정한 경우에만 사용됩니다.

## 검증 상태

- 네 로컬 서비스 기동 및 HTTP 상태 확인 완료
- 대표서식 자동 테스트 17/17 통과
- 챗봇 로컬 근거 검색, 시설안전 화면, MSDS 기본 기능 확인 완료
- Python이 필요한 MSDS 고급 파서와 실제 프린터 출력은 미검증이며 상세 내용은 테스트 보고서에 기록했습니다.
