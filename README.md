# 산업안전보건 서식 웹 자동화 시스템

서울시교육청 산업안전보건 매뉴얼 표준 서식을 웹 브라우저에서 편리하게 작성·전자서명·저장하고, 공문서 양식 그대로 A4 인쇄(PDF 저장) 및 Supabase 클라우드 데이터베이스 연동을 지원하는 웹 애플리케이션입니다.

---

## 📋 탑재된 6종 표준 서식

1. **01-02-01**: `(주1회) 정기점검 실시 및 (월1회) 기관장 보고`
   - 시설관리 / 청소(미화) / 조리(급식실) 3개 분야 탭 전환 지원
   - 주차별 점검일자, 담당/학교장 결재란, 전자서명, 점검내용 및 문제점/개선대책 입력
2. **04-01-03**: `공사(용역) 안전·보건 체크리스트(공통)`
   - 10개 문항 점검(예/아니오/해당없음) + 4종 재해예방 체크리스트 제출 여부
   - 하단 공사(용역)업체 확인·준수 서약서 및 대표자 전자서명
3. **04-01-08**: `안전보건협의체 회의록 및 합동점검`
   - 회의록 / 분기 합동점검 모드 전환
   - 도급자 및 수급자 참석자 명단(서명 포함) 동적 관리
   - 현장 증빙 사진 업로드 및 미리보기
4. **05-02-01**: `안전보건교육일지 (현장교육 시)`
   - 교육일시 및 시간 자동 계산
   - 교육인원(대상자/실시자/미실시자 남·여 자동합계 집계)
   - 20인 참석자 서명부 및 교육사진 증빙 첨부
5. **09-01-05**: `안전보건 교육일지 (근골격계부담작업 유해요인조사)`
   - 6개 표준 교육내용 자동 완성 및 수정 지원
   - 인원 통계, 10인 참석자 서명부
6. **10-01-04**: `안전보건교육일지 (MSDS교육)`
   - MSDS 6대 기본 교육내용
   - 취급 유해화학물질 목록 동적 추가/삭제
   - 인원 통계, 10인 참석자 서명부

## 🚀 실행 방법

### 방법 1: 원클릭 실행
- 폴더 내 **`실행하기.bat`** 파일을 더블클릭하면 브라우저가 열리며 바로 실행됩니다.

### 방법 2: 터미널 실행
```bash
npm run dev
```
브라우저 주소: `http://localhost:5173/`

## 💡 주요 기능 안내

1. **기본 정보 세팅 (자동 완성 프리셋)**:
   - 상단 **`[기본 정보 세팅]`** 버튼을 눌러 소속 학교(기관)명, 담당자/점검자 정보, 교육 강사명, 교육 장소, 결재 서명(점검자/담당자/학교장) 등을 한 번만 등록해 두면, 새로운 서식을 열 때마다 **해당 내용들이 자동으로 채워져** 번거로운 반복 입력을 획기적으로 줄여줍니다.
2. **상단 전체 대형 타이틀 배너 (Top Hero Banner)**:
   - 웹페이지 상단 전체 폭을 활용한 전문적이고 웅장한 비주얼 헤더를 제공하며, 현재 설정된 기본 소속 기관명이 상단 뱃지로 실시간 표시됩니다.
3. **원클릭 인쇄 및 PDF 저장 (`출력 / PDF` 버튼)**:
   - 화면의 입력 도구, 버튼 등은 모두 숨겨지고 실제 교육청 공문서 표준 규격(A4 규격, 결재선, 표 테두리, 서명 이미지)으로 깨끗하게 인쇄 및 PDF로 저장됩니다.
4. **전자서명 패드**:
   - 담당자, 학교장, 점검자, 수급업체 대표, 교육 참석자의 `[서명]` 버튼을 누르면 마우스 또는 터치로 직접 서명할 수 있습니다.
5. **로컬 자동 저장 및 문서 보관함 (`보관함` 버튼)**:
   - 별도 설정 없이도 작성 중인 모든 문서가 브라우저에 영구 보관되며, 검색, 수정, 복사하여 새로 작성, 삭제가 가능합니다.
6. **Supabase 클라우드 DB 연동 (`DB 연동` 버튼)**:
   - 상단 `[DB 연동]` 버튼을 눌러 Supabase URL 및 Anon Key를 등록하면, 다른 동료나 PC와 실시간으로 문서를 공유할 수 있습니다.
   - 제공되는 SQL 생성 쿼리를 Supabase의 SQL Editor에 붙여넣고 Run만 누르면 세팅이 완료됩니다.
