## 통합 후 공통 개선

- 스마트일정관리의 남색 사이드바, 파란색 활성 메뉴, 카드형 화면과 글꼴 체계를 통합 기본 디자인으로 사용
- 다섯 프로그램을 한 메인 화면에서 전환하며 전체 페이지 새로고침 방지
- 전문 모듈 화면은 최초 한 번 생성한 뒤 숨김/표시하여 작성 중 상태 유지
- 전문 모듈과 기존 스마트 간편 기능을 탭으로 함께 제공
- JavaScript·CSS·요소 ID 충돌은 iframe 또는 Shadow DOM으로 차단
- 챗봇/MSDS 포트 충돌을 3001/3000으로 분리
- `실행하기.bat`, `종료하기.bat`, `상태확인.bat` 제공

## 의도적으로 하지 않은 변경

- 서로 다른 프로그램의 업무자료를 자동 병합하지 않음
- localStorage/IndexedDB 키를 임의로 바꾸거나 삭제하지 않음
- API 키·전체 문서·개인정보를 모듈 사이에 자동 전달하지 않음
- Python이 없는 환경에서 MSDS 고급 파서가 정상이라고 가정하지 않음
- 원본 ZIP의 소스와 원본 데이터는 수정하지 않음

데이터 연계는 현재 메뉴 이동 수준으로 제한했습니다. 향후 제목·기한·상태만 일정으로 보내는 선택형 연계를 추가할 수 있도록 허용 출처 기반 메시지 구조를 마련했지만, 사용자의 명시적 확인 없는 자료 이동은 구현하지 않았습니다.
