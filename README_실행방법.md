# 학교 산업안전보건 통합 업무지원 시스템 실행 안내

## 가장 쉬운 실행 방법

1. 이 폴더에서 `실행하기.bat`를 더블클릭합니다.
2. 검은 실행 창을 닫지 말고 잠시 기다립니다.
3. 브라우저에 **학교 산업안전보건 통합 업무지원 시스템**이 열리면 사용합니다.
4. 사용을 마치면 `종료하기.bat`를 더블클릭합니다.

`index.html`은 실행 중인 통합 서버에서 사용하는 시작 문서입니다. 파일을 직접 더블클릭했을 때는 `실행하기.bat`를 사용하라는 안내가 표시됩니다.

## 준비 사항

- Windows 10/11
- Chrome 또는 Edge 최신 버전 권장
- Node.js 20.9 이상

현재 패키지에는 대표서식과 챗봇의 실행용 빌드가 포함되어 있어 `npm install`을 다시 할 필요가 없습니다.

## 상태 확인

`상태확인.bat`를 실행하면 아래 네 서비스의 상태가 표시됩니다.

| 서비스 | 주소 |
|---|---|
| 통합 메인 | `http://127.0.0.1:8080` |
| 대표서식 자동화 | `http://127.0.0.1:5173` |
| MSDS 업무지원 | `http://127.0.0.1:3000` |
| AI 업무지원 챗봇 | `http://127.0.0.1:3001` |

모두 `정상`이면 메인 주소 `http://127.0.0.1:8080/shell/app.html`로 접속할 수 있습니다.

## 메뉴 사용 방법

- 홈/일정·업무관리: 기존 스마트일정관리 기능
- AI 업무지원 챗봇: 25종 업무자료를 근거로 답변하는 전문 챗봇
- 대표서식 자동화: 19종 서식 작성·저장·인쇄
- 시설안전 점검이력: PDF 평가표, 지적사항, 조치·재점검 이력
- MSDS 업무지원: 화학제품 등록, MSDS 관리대장, 라벨·교육자료

전문 기능 화면에서는 `기존 간편기록`을 누르면 스마트일정관리에 있던 기존 간편 기능도 계속 사용할 수 있습니다. 메뉴를 바꾸어도 한 번 연 전문 화면은 유지되어 작성 중인 화면이 불필요하게 초기화되지 않습니다.

## 기존 데이터 가져오기

웹 저장 데이터는 **주소별로 분리**됩니다. 통합 프로그램이 기존과 같은 주소·포트를 사용하는 대표서식(5173)과 MSDS(3000)는 같은 브라우저에서 기존 데이터가 보일 수 있습니다. 스마트일정관리와 시설안전은 기존 실행 주소가 달랐다면 자동으로 합쳐지지 않습니다.

안전한 이전 순서는 다음과 같습니다.

1. 기존 프로그램에서 백업/내보내기 기능으로 파일을 저장합니다.
2. 통합 프로그램의 해당 메뉴를 엽니다.
3. 복원/가져오기 기능으로 저장한 파일을 선택합니다.
4. 자료 개수와 날짜를 확인한 뒤 기존 프로그램은 그대로 보관합니다.

통합 실행기는 기존 저장 키를 삭제하거나 서로 다른 프로그램의 데이터를 자동 병합하지 않습니다.

## MSDS 고급 문서 파서(선택)

MSDS 기본 화면, 로컬 대장, QR/Excel/PDF.js 보조 기능과 규제 DB 모의 조회는 Node.js만으로 동작합니다. 실제 PDF/HWP/HWPX/XLSX 서버 파서는 Python 3.11 이상과 다음 패키지가 추가로 필요합니다.

```powershell
py -3.11 -m pip install -r modules\msds\requirements.txt
```

현재 개발 PC에는 Python이 없어 이 고급 파서는 검증하지 못했습니다. Python을 설치하기 전에도 나머지 통합 프로그램은 실행할 수 있습니다.

## 문제가 생겼을 때

1. `상태확인.bat`를 실행합니다.
2. 오류 서비스가 있으면 `종료하기.bat` 실행 후 `실행하기.bat`를 다시 실행합니다.
3. 계속 실패하면 `runtime\logs\chatbot.log`와 `runtime\logs\msds.log`를 확인합니다.
4. 3000, 3001, 5173, 8080 포트를 다른 프로그램이 사용 중인지 확인합니다.

대표서식 5173 포트에 동일한 기존 프로그램이 이미 실행 중이면 통합 실행기는 그 서비스를 안전하게 재사용합니다. 다른 프로그램이 포트를 사용 중이면 해당 프로그램을 종료한 뒤 다시 실행해야 합니다.

## 개인정보와 외부 연결

- 서버는 PC 내부 주소(`127.0.0.1`)에만 열립니다.
- 통합 작업 과정에서 원본 ZIP이나 업무 데이터를 외부에 업로드하지 않았습니다.
- 챗봇은 API 키가 없으면 내장 자료 검색으로 답변합니다.
- Gemini, Supabase, OpenAI 등 선택형 외부 기능은 사용자가 직접 설정한 경우에만 외부 연결이 발생할 수 있습니다.
- API 키와 개인정보는 통합 모듈 사이에서 자동 전달하지 않습니다.

자세한 변경 사항과 검증 범위는 `reports` 폴더의 보고서를 참고하세요.
