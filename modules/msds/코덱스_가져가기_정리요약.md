## 3. ✨ 개발 및 UI 반영 완료 내역

1. **상단 네비게이션 및 헤더**
   * 불필요한 시연용 노란색/파란색 배너 문구 완전 제거
   * 상단 좌측 **`[⬅ 안심봇으로 돌아가기]`** 버튼 배치 ➔ 메인 챗봇 창으로 자연스러운 복귀 (`window.close()` / 부모 창 포커스)
2. **API 모달 탭 간소화**
   * `🌐 Openrouter API` / `⚡ Gemini API` 직관적인 2개 탭 구성
3. **홈 화면 간결화**
   * 부제 생략, 2개 카드 콤팩트 구성:
     * `📸 신규 화학제품 등록`
     * `📑 기존 관리대장 관리`
4. **기존 관리대장 관리 화면 간소화**
   * **행정실(기본) 대장 등록**: `(엑셀, 한글, PDF)` ➔ `[파일 선택]` ➔ `[📥 대장 등록]`
   * **타 부서 대장 등록 (중복 제외)**: `(엑셀, 한글, PDF)` ➔ `[파일 선택]` ➔ `[➕ 대장 등록]`
   * 중복된 설명 문구를 제거하여 한눈에 들어오는 직관적인 3단 구조로 정돈
5. **3단계 관리조치 드롭다운 및 직접 입력 기능**
   * **사용부서**: `행정실`, `급식실`, `기타`
   * **보관장소**: `시설관리실`, `청소용품실`, `급식실`, `기타`
   * **직접 입력**: `기타` 선택 시 즉시 하단에 입력창이 나타나며, 직접 입력한 부서/장소가 관리대장에 정확히 반영 및 엑셀로 저장

## 4. 🚀 코덱스(Codex) 및 로컬 실행 가이드

### ① 로컬에서 바로 실행할 때
1. **`실행하기.bat`** (또는 `run.bat`) 더블 클릭
2. 브라우저 주소창: `http://localhost:3000`

### ② 코덱스(Codex) 또는 터미널 환경에서 실행할 때
```bash
# 1. 파이썬 라이브러리 설치 (최초 1회)
pip install -r requirements.txt

# 2. 서버 실행
npm start
# 또는
node server.js
```

### ③ API Key 입력 안내
* 서버 구동 후 화면 우측 상단 **`[⚙️ API 설정]`** 아이콘 클릭
* 보유하신 **OpenRouter API Key** 또는 **Gemini API Key**를 입력하면 브라우저에 안전하게 보존되어 즉시 AI 분석이 작동합니다.
