# 🤖 [산업안전 안심봇] MSDS·유해물질 스마트 관리 모듈 — Codex 통합 개발 인수인계서

> **To. Codex (또는 통합 개발 AI/엔지니어)**  
> 본 문서는 **"학교 산업안전 안심봇"** 프로젝트의 5대 핵심 기능 중 **【기능 : MSDS 및 유해화학물질 스마트 관리 시스템】**을 다른 기능들과 유기적으로 통합하고 고도화하기 위한 개발 인수인계 및 아키텍처 설명서입니다.

---

## 1. 📌 모듈 개요 및 핵심 역할

* **모듈명**: MSDS·유해물질 스마트 관리 (`school-msds-ai-app`)
* **역할**: 학교 현장(행정실, 시설관리실, 급식실, 보건실 등)에서 취급하는 모든 화학제품에 대해, **제품 사진 한 장 또는 공식 MSDS PDF**만으로 산업안전보건법 제114조·제115조 의무사항을 원클릭으로 완료할 수 있도록 지원하는 지능형 관리 모듈입니다.
* **주요 해결 과제**:
  1. 복잡한 16개 항목의 MSDS 원문에서 핵심 안전정보(GHS 그림문자, 유해위험문구, 개인보호구) 즉각 자동 추출
  2. 행정실 기본 관리대장과 급식실 등 타 부서 대장(HWPX, HWP, Excel, PDF) 간의 **품목 중복 자동 제거 및 학교 통합 관리대장 구축**
  3. 4대 법정 출력물 자동 생성: **① 공식 GHS 경고표지, ② 소분용기 라벨, ③ 작업공정별 관리요령, ④ 근로자 1페이지 교육자료(PDF)**

## 2. 🏗️ 기술 스택 및 아키텍처 구성

```
[클라이언트: SPA index.html]
   │
   ├─ 1. Gemini / OpenRouter API (이미지 OCR 및 16개 항목 구조화 JSON 추출)
   ├─ 2. LocalStorage (API 키 안전 격리 저장, 학교 통합 대장 데이터 브라우저 영구 보관)
   │
   ▼ HTTP Request (Port 3000)
[백엔드: Node.js server.js (경량 프록시 & 서빙)]
   │
   ├─ 정적 파일 서빙: index.html, 업로드 파일 등
   ├─ /api/proxy-chem-kosha: 공공데이터포털 KOSHA 화학물질 CAS 번호 및 규제 DB 대조
   ├─ /api/proxy-openrouter: OpenRouter AI API 중계
   ├─ /api/extract-pdf-table ──▶ [Python: extract_table.py (PyMuPDF 엔진)]
   │                                  └─ PDF 16개 항목 텍스트 정밀 파싱 & GHS 그림문자 추출
   └─ /api/parse-ledger      ──▶ [Python: parse_ledger.py (HWPX/HWP/Excel 파서)]
                                      └─ 한글 문서 표 구조화 파싱 및 제품명 정규화 중복 필터
```

* **Front-end**: 단일 반응형 HTML (`index.html`), 순수 바닐라 JS (외부 무거운 프레임워크 배제, 로딩 속도 극대화), 자체 CSS 변수 기반 디자인 시스템
* **Back-end**: 경량 Node.js (`server.js`) — `npm` 외부 패키지 설치 없이 Node.js 표준 내장 모듈(`http`, `fs`, `path`, `child_process`)만으로 가동
* **Python Micro-Engines**:
  * `extract_table.py`: `fitz (PyMuPDF)` 기반 PDF 파서
  * `parse_ledger.py`: `zipfile` + `xml.etree` (HWPX 파싱), `olefile` (HWP 5.0 바이너리 스트림 파싱)

## 4. 💡 핵심 구현 알고리즘 및 비즈니스 로직

코덱스에서 다른 안심봇 기능들과 합칠 때 반드시 알고 있어야 하는 핵심 로직입니다:

### 1) 통합 그림문자 보완 엔진 (`getResolvedPictograms`)
* **동작 원리**:
  1. 원문 PDF에서 추출된 그림문자 이미지(`extractedPdfImages`)가 있으면 최우선 사용
  2. AI가 추출한 `pictograms` 배열이 존재하면 사용하되, `해당없음`, `자료없음`, `-` 등의 무효값은 자동 필터링
  3. 만약 그림문자가 비어있다면, **UN GHS 및 안전보건공단(KOSHA) 표준 규칙**에 의거하여 `hazard_statements`의 **H-코드(예: `H332`, `H315`, `H225` 등)**를 정규표현식으로 정밀 분석하여 적합한 GHS 그림문자(느낌표, 불꽃, 해골 등)를 자동 추론·부여합니다.
  4. 신호어가 '경고' 또는 '위험'인데 유해위험문구가 존재할 경우 기본 느낌표(`경고/자극성`)를 안전장치로 자동 매핑합니다.
* **적용 범위**: GHS 경고표지, 소분용기 라벨, 작업공정별 관리요령, 근로자 교육자료(미리보기 & PDF) 전 영역에 100% 동일하게 일관 적용됩니다.

### 2) 기존 대장 중복 자동 필터링 알고리즘
* **함수**: `normalizeProductName()`, `sanitizeLedgerRows()`
* 공백, 특수문자, 대소문자를 정규화(`노루씰 7500` ➔ `노루씰7500`)하여 비교합니다.
* 행정실 기본 대장 등록 시 전체 품목을 기준(베이스라인)으로 잡고, 급식실 등 타 부서 대장 등록 시 이미 기본 대장에 존재하는 제품은 자동 제외되며, **순수 신규 품목만 `isNew: true` 플래그**를 받아 상단에 돋보이게 추가됩니다.

### 3) 사용부서 및 보관장소 동적 직접 입력
* **사용부서**: `행정실`, `급식실`, `기타`
* **보관장소**: `시설관리실`, `청소용품실`, `급식실`, `기타`
* `기타` 선택 시 동적으로 `<input type="text">` 필드가 활성화되며, 사용자가 입력한 부서/장소명이 관리대장 저장 및 엑셀 다운로드 파일에 그대로 반영됩니다.

### 4) 메인 안심봇 복귀 인터페이스
* 상단 헤더 좌측에 **`[⬅ 안심봇으로 돌아가기]`** 버튼이 구비되어 있습니다.
* 호출 함수: `returnToMainBot()`
* 메인 안심봇 창에서 팝업/새 창으로 띄웠을 경우 부모 창 포커스 및 창 닫기를 수행하며, 단독 실행 시 홈 화면으로 부드럽게 복귀합니다.

## 5. 🚀 코덱스(Codex)에서 통합하는 방법 가이드

### [옵션 A] 서브모듈 / 독립 마이크로서비스 연동 (가장 추천 & 빠름)
* 안심봇 메인 서버(Express, Fastify, Next.js 등)에서 이 앱을 3000번 포트(또는 다른 지정 포트)의 백그라운드 프로세스로 띄우고, 챗봇 대화창에서 `[MSDS 관리 바로가기]` 버튼 클릭 시 해당 URL로 새 탭 또는 iframe으로 연결합니다.
* 장점: 기존에 완벽하게 검증된 PDF/HWP 파서, AI 추출 로직, 인쇄 팝업 스타일을 100% 그대로 활용할 수 있습니다.

### [옵션 B] 코덱스 메인 백엔드 라우터로 API 흡수
* `server.js`에 정의된 4대 핵심 엔드포인트를 코덱스 메인 백엔드 서버로 복사/이전:
  1. `POST /api/proxy-chem-kosha` (화학물질 규제 DB 대조)
  2. `POST /api/proxy-openrouter` (OpenRouter API 프록시)
  3. `POST /api/extract-pdf-table` (`extract_table.py` 호출)
  4. `POST /api/parse-ledger` (`parse_ledger.py` 호출)
* `index.html`의 CSS/JS를 메인 프론트엔드 라우트(예: `/msds`)에 마운트합니다.

### [옵션 C] React / Vue / Next.js 컴포넌트화 시 주의사항
* GHS 벡터 아이콘(`GHS_SVGS`)은 SVG 문자열 딕셔너리로 구성되어 있으므로 리액트 컴포넌트로 손쉽게 이식이 가능합니다.
* 인쇄 기능(`window.open` 기반 `openPrintPopup`)은 브라우저 팝업 차단에 유의하여 클릭 이벤트 핸들러 내부에서 동기적으로 팝업 창을 열도록 설계되어 있습니다.

## 6. ⚙️ 로컬 테스트 및 구동 명령어

```bash

# 2. 서버 실행
npm start
# 또는 
node server.js

# 3. 브라우저 접속
http://localhost:3000
```

> 화면 우측 상단 `[⚙️ API 설정]`에서 OpenRouter Key 또는 Gemini Key를 등록하면 클라이언트 LocalStorage에 안전하게 저장되어 AI 분석이 바로 동작합니다.
